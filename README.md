# TikSouls public demo

A buildless browser demo for GitHub Pages. Publish the files at the root of the `main` branch in the public `hassanelmokadem44/TikSouls-Downloads` repository. Under **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**.

Publish the Windows installer ZIP as an asset on the `v1.1.53` release. The website links to the latest release. Keep the desktop app source in a private repository.
